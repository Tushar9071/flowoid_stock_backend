Executive Map

Tenant-based backend. Finished inventory emerges from manufacturing activity, packaging, adjustments, and dispatch. Dealer outstanding is derived from opening balances, sale ledger entries, and payments.

Sales Rule

Packaged stock required

Orders can be drafted but confirmed only when packaged dozens are available after reservations.

Manufacturing

Worker returns drive stock

Accepted returned pieces become unpackaged stock; rejected pieces are tracked separately.

Finance

Event-driven ledger

Dispatch creates SALE debit; payments create credit entries. Reversals handled explicitly.

Documents

PDF + WhatsApp

Invoices/challans generated after dispatch. WhatsApp uploads to Meta and logs status.

Business Scenarios

Scenario 1: Purchase → Sale → Payment 
flowchart LR A[Supplier] --> B[Raw Purchase] --> C[Assignment] --> D[Return] --> E[Package] --> F[Order] --> G[Dispatch] --> H[Payment]
  1. Create supplier & raw material type.
  2. Record RECEIVED purchase.
  3. Worker assignment with automatic issuance.
  4. Goods return → unpackaged stock.
  5. Package into dozens, then confirm order.
Scenario 2: Dealer wants Item X (no stock)

Check design active → packaged stock? If not, unpackaged? else raw material → assign worker → return → package → confirm.
